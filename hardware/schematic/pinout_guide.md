# Pinout & Wiring Guide — Electronic Butterfly (ESP32-C3) 🦋

เอกสารระบุผังการต่อขาพินและโทโพโลยีการเดินสายไฟตามข้อกำหนดระบบอย่างเป็นทางการ

---

## 1. ผังการกำหนดขาพิน ESP32-C3 SuperMini (Control Signals)

| ขาพิน ESP32-C3 | ฟังก์ชันการทำงาน | อุปกรณ์ปลายทาง | ประเภทสัญญาณ | หมายเหตุสำคัญ |
| :--- | :--- | :--- | :--- | :--- |
| **GPIO 2** | PWM ออก | เซอร์โวปีกซ้าย (Left MG90S) | PWM 50 Hz (3.3V Logic) | ควบคุมมุมปีกซ้าย $15^\circ - 85^\circ$ |
| **GPIO 3** | PWM ออก | เซอร์โวปีกขวา (Right MG90S) | PWM 50 Hz (3.3V Logic) | ควบคุมมุมปีกขวากลับด้าน: `Angle = 180 - Left_Angle` |
| **GPIO 4** | Digital Data ออก | หลอด WS2812B / SMD LED บนปีก | High-Speed Serial Data | ต่ออนุกรมผ่านตัวต้านทาน $330\ \Omega$ ก่อนเข้าขา DIN |
| **GPIO 9** | Digital เข้า (Pullup) | ปุ่ม BOOT บนตัวบอร์ด | Input Active-LOW | กดสลับโหมดพฤติกรรมการบินเมื่อไม่ได้ต่อ Wi-Fi |
| **5V (VIN)** | รับไฟเลี้ยงหลัก | จากขั้ว Cathode ของไดโอด 1N5819 | Power In ($4.8\text{V} - 5.0\text{V}$) | มีไดโอด 1N5819 คั่นป้องกันไฟ 5V ย้อนเข้า PC |
| **GND** | กราวด์ร่วม | กราวด์รวม (Star Ground Bus) | Power Return | ต่อร่วมกับ 5V Boost, คาปาซิเตอร์ 470µF และ Servos |

## 2. การแบ่งโซนพลังงานและการป้องกันระบบไฟ (Two-Zone Architecture)

### [ โซนฐานตั้ง: Power Core ]
ซ่อนอุปกรณ์พลังงานทั้งหมดไว้ภายในฐานตั้ง `base_stand.stl` เพื่อจุดศูนย์ถ่วงต่ำและลดสายไฟ:
1. **พอร์ต USB-C** รับไฟ $5\text{V}$ เข้าโมดูลชาร์จ **TP4056**
2. **TP4056** ต่อชาร์จแบตเตอรี่ **Li-ion 14500 (3.7V)** ทางขั้ว `B+` และ `B-`
3. ขั้ว `OUT+` ของ TP4056 ต่อผ่าน **สวิตช์เลื่อน (Slide Switch)** เข้าขา `VIN` ของ **โมดูล Step-Up Boost 5V**
4. ขั้ว `OUT-` ของ TP4056 ต่อเข้า `GND` ของโมดูล Step-Up Boost
5. **สายไฟขึ้นก้านลำตัวผีเสื้อมีเพียง 2 เส้น:**
   - **สายสีแดง:** ไฟ $5\text{V}$ จากเอาต์พุตของโมดูล Step-Up Boost
   - **สายสีดำ:** สายดิน `GND`

### [ โซนลำตัวผีเสื้อ: Main PCB & Actuators ]
ติดตั้งบนแผ่นวงจรในส่วนอก (Thorax) และส่วนท้องโปร่ง (Abdomen Capsule):
1. **Schottky Diode (1N5819):**
   - ต่อคั่นสายไฟ $5\text{V}$ จากก้านลำตัว (Anode) ก่อนเข้าขา $5\text{V}$ ของบอร์ด ESP32-C3 (Cathode)
   - **เหตุผลทางวิศวกรรม:** ป้องกันไฟ $5\text{V}$ จากแบตเตอรี่และไฟ $5\text{V}$ จากพอร์ต USB ของคอมพิวเตอร์ชนกันเวลาเสียบสายอัปโหลดโค้ดหรือทำ Simulation
2. **Electrolytic Capacitor (470µF – 1000µF, 10V/16V):**
   - ต่อคร่อมสายไฟ $5\text{V}$ และ `GND` ใกล้ขั้วต่อเซอร์โวมากที่สุด
   - **เหตุผลทางวิศวกรรม:** ซับกระแสกระชาก (Inrush current $> 400\text{ mA}$) เวลาเซอร์โว MG90S เปลี่ยนทิศทางกระพือปีกอย่างรวดเร็ว ป้องกันแรงดันไฟตกจนชิป ESP32-C3 เกิด Brownout Reset
3. **ตัวต้านทาน 330Ω:**
   - ต่ออนุกรมระหว่าง GPIO 4 และสายสัญญาณข้อมูล DIN ของหลอดไฟบนปีกทั้งสองข้าง

## 3. การเดินสายไฟข้ามบานพับปีก (Spring Coiled Enamel Wire)
- ใช้ **ลวดทองแดงอาบน้ำยาขนาด $\varnothing 0.2\text{ mm}$** จำนวน 3 เส้น (5V, GND, Data)
- บริเวณจุดหมุนบานพับปีก ให้**ขดลวดเป็นสปริงวงกลม $2–3$ รอบ** ลอยตัวอยู่เหนือแกนหมุน
- รูปทรงสปริงจะกระจายแรงดัด (Bending stress) ทำให้ลวดไม่ขาดและไม่สร้างแรงต้านทานต่อการหมุนของเซอร์โว
